# Chapter 3: The New UI/UX Paradigm

For the last 30 years, we have learned to interact with software in only one way: clicking, scrolling, and filling out forms. However, in AI-Native applications, the interface is no longer "static." In this chapter, we will explore how **Conversations are replacing Buttons** and how software now physically changes its shape to meet the specific needs of the user.

---

## Topic 1: From GUI to LUI (Language User Interface)

Until now, we have lived in the era of the **GUI (Graphical User Interface)**, where every specific action required a specific button. AI has given birth to the **LUI (Language User Interface)**.

### 1.1 Intent-Based Design

In **traditional software**, the user has to find a "Path" to get something done:

> Settings → Profile → Privacy → Change Password

In **AI-Native software**, the user simply states their **Intent** (their goal):

> *"Hey, tighten up my privacy settings."*

The software already knows where those settings are located. Instead of making the user navigate the path, the software **executes the action** and presents the result immediately.

### 1.2 The Death of the "Search Bar"

In the past, the search bar only looked for keywords. Now, the search bar has evolved into an **"Action Bar."** Users no longer just ask questions — they give commands. We call this **Natural Language Command.**

This leads to a much cleaner interface because you no longer need to crowd the screen with every possible menu or button.

## Topic 2: Generative UI and Adaptive Experiences

This is the most advanced concept of this chapter. Imagine software that **looks different for every single user** based on what they are doing.

### 2.1 What is Generative UI?

**Generative UI** means that interface components (buttons, charts, cards) are not pre-built by a designer. Instead, the AI generates them **"on-the-fly"** based on the context of the conversation.

> **Example:** If you ask the AI, *"How much did I spend this month?"*, the AI won't just reply with text. It will instantly generate a **Pie Chart** on your screen specifically for that question. As soon as your question is answered and the task is complete, that chart disappears. The interface only shows what is necessary at that exact moment.

### 2.2 Adaptive Friction (The Importance of Human-in-the-Loop)

The old rule of UX was to reduce **"Friction"** (obstacles) as much as possible. However, in AI, we need **"Rightful Friction."**

Because AI can sometimes make mistakes (**Hallucinations**), AI-Native design incorporates **"Human-in-the-loop"** moments:

- When an AI takes a **high-stakes action** (for example: transferring money from a bank account), the interface must **pause** and ask the user to **Confirm**.
- The goal of AI-Native UX is not "Full Automation," but **"Shared Control"** between the human and the machine.

  title="Generative UI — Render on Context"
  language="typescript"
  code={`const ui = await agent.generateUI(
  "How much did I spend this month?"
);

// AI returns a contextual component, not just text
// e.g. { type: "PieChart", data: spendingByCategory }
